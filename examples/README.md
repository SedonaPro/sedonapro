# Примеры

Пример — кусок приложения, который добавляется к приложению по умолчанию цели.
Работают на виртуальной плате `sim`: входы задаются в панели `http://127.0.0.1:8090`.

| Пример | Уровень | Что показывает |
|---|---|---|
| `blink` | 1 | таймер и дискретный выход: DO2 мигает раз в секунду |
| `thermostat` | 2 | аналоговый вход, регулятор `hvac::Tstat`, выход на нагреватель |
| `mqtt` | 3 | тот же термостат по MQTT: температура, нагреватель и статус online/offline уходят брокеру, уставка и AO2 приходят от него |
| `booster` | 3 | насосная станция: 3 насоса на общем ЧРП, ПИД давления, каскад, ротация, аварии, сухой ход (`--pack pumps`) |
| `ahu` | 3 | приточная установка из конфигуратора `sproAhu::Ahu`: водяной калорифер с защитами, ЧРП, кнопка пуска (`--pack hvac --board sim-large`) |
| `ahu-schedule` | 3 | та же установка по недельному расписанию с праздниками и оптимальным пуском (`sproSched`; `--pack hvac --board sim-large`) |
| `pump-station` | 2 | насосная станция `booster`, но из конфигуратора `sproPumpSt::PumpStation`: собирается сама при первом пуске (`--pack pumps`) |
| `heating` | 3 | ИТП: отопление по погоде с ограничением обратки и ночным снижением, ГВС с приоритетом и дезинфекцией по расписанию, подпитка (`--pack heat --board sim-large`) |
| `heat-station` | 2 | тот же ИТП из конфигуратора `sproHeatSt::HeatStation`: сдвоенные насосы, ГВС с циркуляцией, подпитка, общая авария; собирается сам при первом пуске (`--pack heat --board sim-large`) |
| `energy` | 3 | электроснабжение: АВР на два ввода и ДГУ, учёт по трём тарифным зонам, лимит 30-минутной мощности с отключением двух нагрузок (`--pack energy --board sim-large`) |

```sh
./spro build sim --example blink,thermostat
./spro run sim --erase
./spro build linux --example thermostat && ./spro run linux
```

Пример `mqtt` с брокером на этом ПК (три терминала):

```sh
./spro broker                                   # 1: брокер, печатает каждое сообщение
./spro build sim --example mqtt && ./spro run sim --erase   # 2: контроллер
./spro pub sedonapro/demo/sp/set 23             # 3: новая уставка; DO4 включится
```

Насосная станция: `./spro build sim --pack pumps --example booster`, затем в
панели AI1 ниже 4 — насосы включаются по очереди, DI2 — авария насоса 2, DI4 —
сухой ход (подробно — `kits/equip/sproEquip/README.md`).

Пример может заменить демонстрационный фрагмент приложения с теми же каналами:
`<module replaces="hal">`.

Свой пример: XML с `<kit>` (какие kits нужны), `<into path="">` (куда добавить
компоненты) и `<link>` (связи). Образец — `blink.xml`.
