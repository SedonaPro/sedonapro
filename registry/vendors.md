# Kit vendors and prefixes

sedonac requires every kit name to start with its vendor name (case-insensitive).
SedonaPro kits use vendor `SPro` and the prefix `spro`.

Publishing your own kits for SedonaPro: pick a short lowercase prefix, check that
it is not in this table, add a row in a pull request, and use it as `vendor` in
your kit.xml (for example vendor `Acme`, kits `acmeBoiler`, `acmeFan`).

| Prefix | Vendor | Owner | Contact |
|---|---|---|---|
| spro | SPro | SedonaPro project | this repository |
