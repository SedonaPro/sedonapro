# sproBase

Фундамент профессиональных kits SedonaPro (`docs/pro-kits.md`): общие коды
состояния, режим Auto/Hand/Off, моточасы, сохранение счётчиков при пропаже питания.

| Компонент | Что делает |
|---|---|
| `Hoa`, `HoaBool` | переключатель Auto/Hand/Off аналоговой или дискретной команды |
| `RunCounter` | моточасы, число пусков, напоминание о сервисе |
| `RetainService` | сохраняет счётчики всех компонентов-`Retained` в файл и восстанавливает при старте |

Для разработчиков kits: `Pro` — общие коды `status` (`Pro.statusRange`) и режимов
(`Pro.modeRange`), проверка `Pro.valid(x)`; `Ticker` — шаг времени компонента;
`Retained` — база для компонентов, которым нужна память между перезапусками.

## Сохранение счётчиков

Добавьте один `RetainService` в `Services`. Он пишет файл `retain.dat` раз в
`interval` минут (по умолчанию 10), при остановке приложения и через 5 с после
ручного изменения (сброс, установка моточасов). При пропаже питания теряется не
больше `interval` минут счёта. Файл пишется во временный и переименовывается,
повреждённый файл отбрасывается по контрольной сумме (`status = badFile`).
