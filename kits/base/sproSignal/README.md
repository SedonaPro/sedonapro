# sproSignal

Обработка измерений: от сырого сигнала датчика до достоверного значения в
инженерных единицах. Правила поведения — `docs/pro-kits.md`.

| Компонент | Что делает |
|---|---|
| `Scale` | линейное масштабирование 4–20 мА / 0–10 В, обрыв и КЗ по NAMUR NE 43 (`badLo` 3,6 мА, `badHi` 21 мА) |
| `Divider` | сопротивление датчика в делителе напряжения (вход АЦП → Ом) |
| `Rtd` | температура по сопротивлению: Pt100/Pt500/Pt1000 (IEC 60751), Ni100/Ni1000 (DIN 43760), Ni1000 TK5000, NTC (beta); `offset` — калибровка |
| `Curve8` | таблица до 8 точек с линейной интерполяцией (характеристики, графики) |
| `Lag` | фильтр первого порядка (постоянная времени, с) |
| `MovingAvg` | скользящее среднее за окно (15-минутная мощность, средняя за час) |
| `Median` | медиана 5 последних отсчётов — убирает одиночные выбросы |
| `Validate` | достоверность: диапазон, скорость изменения, «замёрзшее» значение; задержки `badDelay`/`goodDelay` |
| `Select4` | одно значение из 4 датчиков без неисправных: среднее, мин, макс, медиана (2 из 3), первый исправный; расхождение `maxSpread` |
| `Totalizer` | интеграл расхода/мощности (м³/ч → м³, кВт → кВт·ч), сохраняется при пропаже питания |
| `PulseCounter` | счёт импульсов счётчика, итог и расход за час |
| `RateOfChange` | скорость изменения в секунду, минуту или час |
| `Threshold` | порог с гистерезисом и задержками (аварийный предел, термостат защиты) |

Неверный вход (`null`, обрыв, вне диапазона) даёт `status = inputBad`, а выход
по настройке `onBad`: держит последнее (`hold`), уходит в `fallback` или
передаёт `null` дальше.

`Totalizer` и `PulseCounter` сохраняют итог между перезапусками, если в
приложении есть `RetainService` (`sproBase`).

Лицензия: Apache 2.0.
