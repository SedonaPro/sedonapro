# sproAlarm

Аварии и защиты. Правила — `docs/pro-kits.md`.

| Компонент | Что делает |
|---|---|
| `LimitAlarm` | предел измерения: выше `hi` / ниже `lo` с гистерезисом; неверное значение — тоже авария |
| `BoolAlarm` | авария дискретного сигнала (аварийный контакт, реле фильтра) |
| `MismatchAlarm` | расхождение команды и обратной связи |
| `Trip` | защита с автоповтором: при условии (сухой ход, высокое давление, мороз) `ok = false`, через `retryDelay` повтор; после `retries` срабатываний за `retryWindow` — блокировка до квитирования |
| `AlarmSum` | общая авария группы и первопричина (first-out) |
| `AlarmService` | число активных и неквитированных аварий, общий выход аварии, последнее событие текстом, «квитировать всё», журнал `alarms.csv` |

Общее у всех аварий: `delay` (условие должно продержаться), `clearDelay`,
`latch` (держится до квитирования), `inhibit` (подавление при пуске, летом),
`priority` (`critical, high, medium, low`), `text` для журнала и панели,
квитирование действием `ack`, фронтом `ackIn` или `AlarmService.ackAll`.

Журнал: строки `дата время;raise|clear|ack;приоритет;папка/имя;текст`; при
превышении `maxSize` старшая половина отбрасывается. Без часов (`DateTimeService`)
время пишется от старта (`+123s`).

Лицензия: Apache 2.0.
