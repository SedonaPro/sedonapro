# sproHeat

Индивидуальные тепловые пункты (ИТП): отопление по погоде, горячее
водоснабжение, подпитка. Правила — `docs/pro-kits.md`. Насосы подключаются через
`sproEquip::Motor` или `LeadLag` (защиты, моточасы, прокрутка), расписания —
`sproSched`. Готовый ИТП из этих блоков собирает конфигуратор
`sproHeatSt::HeatStation` (с мнемосхемой).

| Компонент | Что делает |
|---|---|
| `HeatCurve` | отопительный график по наружной температуре от расчётной точки (95/70 при −28 °C): показатель отопительных приборов, параллельный сдвиг, ночное снижение (`setback`), коррекция по температуре помещения, пределы подачи; уставка обратки по тому же графику; отопление вкл/выкл по средней наружной температуре с гистерезисом (`heatOn` / `heatOff`) |
| `HeatingCircuit` | контур отопления: ПИ-регулятор подачи; ограничение обратки сдвигом уставки (П + И, ниже предела не действует); ограничение клапана для приоритета ГВС (`limit`); клапан открывается только при подтверждённой циркуляции (`flow`, `flow2`), короткую потерю — переключение насосов — пережидает в прежнем положении (`flowLoss`); перегрев — клапан закрыт сразу, авария; защита от замерзания по наружной температуре и по воде в любом режиме; выбег насоса |
| `DhwCircuit` | ГВС: быстрый ПИ-регулятор, защита от ожога (клапан закрыт сразу выше `highLimit`), термическая дезинфекция по фронту `disinfect` (из расписания) или действием — с контролем температуры и времени, авария при неудаче; приоритет ГВС над отоплением (`heatingLimit` → `HeatingCircuit.limit`); отказ датчика закрывает клапан |
| `MakeUp` | подпитка: клапан или насос по давлению с гистерезисом, пауза между подпитками; слишком долгая подпитка — остановка до сброса; частые подпитки — предупреждение «утечка»; низкое и высокое давление |

Связи (как в `examples/heating.xml`):

```
наружная → HeatCurve.outdoor → supplySp, returnSp, heating → HeatingCircuit
HeatingCircuit.valve → AO клапана, pump → Motor.request; Motor.running → HeatingCircuit.flow (сдвоенные насосы: второй → flow2)
DhwCircuit.heatingLimit → HeatingCircuit.limit (приоритет ГВС)
WeekSchedule.occupied → (Not) → HeatCurve.setback; другое расписание → DhwCircuit.disinfect
давление обратки → MakeUp.pressure → out → клапан подпитки; MakeUp.low → остановка насосов
```

Проверка: `test/HeatTest.sedona` — график в расчётной точке и при 0 °C, контур
на модели (выход на уставку без перерегулирования больше 2 K, ограничение
обратки, приоритет, перегрев, мороз), ГВС с дезинфекцией, подпитка. Тесты
переносимые: идут и в симуляторе ESP32.

Лицензия: Apache 2.0.
