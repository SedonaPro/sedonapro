# Проверка версии 0.2.0

Дата: 10 ноября 2026. 21 собственный тестовый сценарий sproSim плюс стандартный набор sys.

| Среда | Успешных assert вместе с sys | Ошибок |
|---|---:|---:|
| Windows SVM 1.2.28, refSize=4 | 8346 | 0 |
| Linux amd64 SVM 1.2.29-bclimate, refSize=8 | 8345 | 0 |

Один дополнительный assert sys исполняется только при refSize=4 и проверяет размер Link.
Счётчик assert не означает тысячи независимых испытаний нового PID.

Дополнительно запускались обычные приложения через реальный планировщик VM:

- два независимых контура ×1 и ×60;
- отказ датчика в заданный момент модельного времени;
- изменение воды 60→45 °C: сравнение контура с feedforward и без него;
- каскад помещения и притока: более 10000 модельных секунд, изменение воды и уставки помещения.

Новые тепловые сценарии проверены и на Windows, и на Linux amd64. Значения сравнения feedforward совпали по печатаемой точности.
Конечные времена каскадного прогона могут немного различаться из-за реального времени завершения тестового процесса; сравнивать следует строки одного модельного времени.
У Windows на секунде 10980: помещение 23.007187 °C. У Linux на секунде 10950: 23.007645 °C. Цель 23 °C, допуск испытания ±0.1 °C.

Проверены независимые часы, pause/step/reset, бюджет/backlog, фиксированный dt, недопустимые связи/конфигурации,
модели первого порядка, задержки, привод, датчик, PI и PID, D без скачка по уставке, tracking, динамические пределы,
защита интегратора от насыщения, external reset ведущего PID, сохранение энергии, аналитическое стационарное решение теплообменника,
обратная модель feedforward, модель помещения и интерполяция Lookup5.

Сборка архива проверяет SHA-256 всех исходников src по меткам успешных локальных, серверных и тепловых испытаний.
Сам архив содержит source hashes, отчёт, логи и SHA256SUMS рядом с ZIP.
Серверный стенд запускался в /tmp/mcs-sim-check-20261110 отдельным процессом; рабочая служба sedonapro-sedona и её приложение не изменялись.

Это проверка программной реализации и согласованной учебной модели. Она не заменяет идентификацию реальной установки,
физические измерения, приёмку защит и промышленную валидацию регулятора.
