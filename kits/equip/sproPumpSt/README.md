# sproPumpSt

Конфигуратор насосной станции: повысительной или циркуляционной, 1–4 насоса,
поддержание давления (или перепада с одного датчика). Как `sproAhu::Ahu`:
выбираете состав в свойствах и вызываете `build` — компонент наполняет себя
блоками `sproEquip` и `sproAlarm`, точками входов-выходов платы и связями.

```
press → pid → casc (каскад, сон) → lead (основной/резервный, ротация) → m1..m4 (Motor) → do1..do4
```

| Опция | Варианты |
|---|---|
| `pumps` | 1–4 |
| `drive` | `onOff` (пуск/стоп, выход ПИД ставит ступени), `commonVfd` (общий ЧРП, AO `vfd`), `vfdEach` (AO на каждый насос) |
| `dryRun` | `none`, `switch` (реле давления на всасе, `true` — нет воды), `sensor` (датчик давления на всасе, порог 0,3/0,5 бар) — отключение всех насосов через `Trip` с повторными попытками |
| `faultInputs` | вход аварии на каждый насос (тепловое реле, авария ЧРП) |
| `feedback` | контакт работы на каждый насос (`Motor.checkFeedback`) |
| `pressureAlarms` | аварии высокого и низкого давления (`LimitAlarm`) |
| `sleepMode` | сон без водоразбора (`PumpCascade.sleep`) |
| `startSwitch` | пуск с DI вместо `request` |

Уставка — `pid.sp`. Повторная сборка сохраняет блоки того же типа с их
настройками (наработка насосов, уставки), ненужные части удаляются. Каналы
платы берутся по порядку (`autoChannels`), что куда попало — в `ioList`.

Виджет `pumps` — мнемосхема станции для веб-редактора и Sedona Studio: на
стороне «Настройка» состав и «Собрать…», на стороне «Работа» насосы,
скорость, наработка, давление, уставка и режимы насосов.

Пример: `examples/pump-station.xml` (`./spro build sim --pack pumps --example pump-station`).
