# sproEquip

Насосы, вентиляторы, компрессоры: один агрегат, группа с ротацией, каскад
насосов на общем частотнике. Правила — `docs/pro-kits.md`.

| Компонент | Что делает |
|---|---|
| `Motor` | агрегат: запрос → команда контактору; Auto/Hand/Off, задержка пуска и выбег, мин. время работы/простоя, задержка после подачи питания, авария (с защёлкой), разрешение `permit`, контроль обратной связи с автоповтором, моточасы и пуски, прокрутка после долгого простоя, скорость для ЧРП |
| `LeadLag` | группа до 6 агрегатов: основной/резервный (`request`) или каскад (`demand`); ротация по наработке, по времени или фиксированная; мгновенная замена отказавшего; перекрытие при смене (`overlap`) |
| `PumpCascade` | каскад насосов на общей скорости: добавляет насос, когда скорость выше `upAt`, снимает ниже `downAt`; режим «сна» при отсутствии разбора |

## Насосная станция повышения давления

```
AnalogInput (давление) → Pid (sp 4 бар) → PumpCascade → LeadLag → Motor ×3 → DO1..DO3
                                            └ speed ──────────────→ Motor.speedIn, AO (ЧРП)
Trip (сухой ход) → Motor.permit;   DI (тепловое реле) → Motor.fault
Motor.available → LeadLag.availN;  LeadLag.availableCount → PumpCascade.available
PumpCascade.sleeping → Pid.track   (trackValue = minSpeed)
```

Готовое приложение: пример `booster` (`examples/booster.xml`):

```sh
./spro build sim --pack pumps --example booster && ./spro run sim --erase
```

Панель `http://127.0.0.1:8090`: AI1 — давление, DO1..DO3 — насосы, AO1 — скорость,
DI1..DI3 — аварии насосов, DI4 — сухой ход.

Проверено сценарием `sproScenarios/test/PumpStationTest.sedona` на модели сети
(характеристика насоса, разбор, утечка): 1 → 3 насоса на пике без просадки ниже
3,7 бар, замена отказавшего, «сон» ночью и пробуждение по утечке.

## Наладка

- `PumpCascade.downAt` — ниже скорости, на которой насосы работают, когда на один
  меньше ещё держит давление, но выше скорости при нулевом расходе; `sleepSpeed` —
  чуть выше скорости при нулевом расходе. Оба зависят от характеристики насосов и
  уставки и подбираются на объекте.
- `Motor.checkFeedback` включайте, если есть контакт обратной связи (блок-контакт,
  реле перепада, реле потока).
- Моточасы `Motor` и наработка в `LeadLag` переживают перезапуск при наличии
  `RetainService` (`sproBase`).
