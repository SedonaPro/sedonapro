# sproHvac

Приточные и приточно-вытяжные установки. Блоки — законченные узлы со своими
защитами; внутри работают регуляторы `PidAlgo` из `sproControl` (безударные,
без насыщения интегратора). Правила — `docs/pro-kits.md`.

| Блок | Что делает |
|---|---|
| `Season` | зима / межсезонье / лето: вручную или автоматически по средней за `averaging` ч наружной температуре, с гистерезисом и минимальным временем в сезоне; действие `decide` — решить сейчас |
| `AhuControl` | режимы `auto` (по запросу), `on`, `off`; пуск: прогрев калорифера → заслонки (время и концевик) → вытяжной → приточный → регулирование; останов: выбег и продувка электрокалорифера; пожар (стоп или только вытяжка); мороз; авария вентилятора с защёлкой |
| `SupplyTemp` | приток или каскад «помещение → приток» с пределами; раздельные регуляторы нагрева и охлаждения с нейтральной зоной; сначала рекуператор (`recShare`), потом нагреватель; сезон разрешает нагрев/охлаждение |
| `WaterHeater` | водяной калорифер (подробно ниже) |
| `ElectricHeater` | ступени (линейно или 1-2-4) и ШИМ-ступень на SSR между ними, блокировка по потоку воздуха, перегрев с защёлкой, продувка |
| `Recuperator` | пластинчатый, роторный, гликолевый: по запросу; защита от обмерзания регулятором по температуре выброса (без остановки установки), оттайка по реле перепада; летом — рекуперация холода, когда снаружи теплее; минимум для ротора |
| `FanSpeed` | постоянные скорости комфорт/эконом или поддержание давления в канале, повышение по CO₂, плавный разгон, ограничение от защиты калорифера |

## WaterHeater — защиты калорифера

- **Подпор зимой.** Минимальное открытие клапана по наружной температуре
  (`minLo` при `minOutdoorLo`, `minHi` при `minOutdoorHi`): при −25 °C
  калорифер не стоит холодным, даже если тепла не просят.
- **Ограничение сверху в межсезонье и летом.** Максимум клапана по наружной
  температуре (100 % при `maxOutdoorLo`, `maxHi` при `maxOutdoorHi`).
- **Нижний предел обратной воды в работе.** Второй регулятор держит обратку
  выше уставки по наружной температуре и перехватывает клапан плавно (выбор
  максимума с external reset). Ближе к `tripReturn` его усиление растёт до
  `kp × (1 + boost)`: клапан открывается агрессивнее. Открывается он быстро
  (`retTi`), закрывается медленно (`retTiDown`).
- **Снижение скорости вентиляторов.** В зоне опасности (`warnReturn` →
  `tripReturn`, `warnAir` → `tripAir`) `fanLimit` снижается до `fanMinFrost`.
  Холодного воздуха становится меньше, у воды больше времени. Обратно
  скорость возвращается медленно (`fanRecover`).
- **Дежурный режим.** При остановленной установке в холодный период обратка
  держится по своей уставке (`retStandbyLo`/`Hi`).
- **Прогрев перед пуском.** Клапан не меньше `preheatValve`, пока обратка не
  дойдёт до дежурной уставки (не меньше `preheatMin`). `ready` разрешает пуск
  вентиляторов.
- **Авария «мороз».** Обратка ниже `tripReturn`, приток ниже `tripAir` или
  термостат в течение `tripDelay`: клапан 100 %, насос, `fanLimit` 0, `frost`
  останавливает установку. Когда вода снова тёплая, автоматический перезапуск
  (`autoRestart` раз), дальше только сброс вручную.
- **Компенсация температуры теплоносителя.** Если сеть даёт воду холоднее
  `waterNominal`, клапан открывается заранее: множитель
  `(waterNominal − воздух) / (вода − воздух)`.
- **Отказ датчика обратки** в холодный период: клапан `valveOnBad`, авария.

Защиты по обратке и притоку работают только в холодный период: зимой или при
наружной температуре ниже `standbyBelow`. Летом калорифер не подтапливается.

## Связи установки

```
Season.season → SupplyTemp, WaterHeater, Recuperator
AhuControl.control → SupplyTemp.run, Recuperator.run;  .supplyFan → FanSpeed.run
AhuControl.heaterStart → WaterHeater.startReq;  .airflow → WaterHeater.airflow, ElectricHeater.airflow
WaterHeater.ready → AhuControl.heaterReady;  .frost → AhuControl.frost;  .fanLimit → FanSpeed.limit
SupplyTemp.heating → WaterHeater.demand | ElectricHeater.demand;  .recovery → Recuperator.demand
ElectricHeater.purge → AhuControl.purge
```

## Проверка

`sproScenarios/test/AhuTest.sedona` — установка на модели калорифера `WaterCoil`
(около 3000 м³/ч, 45 кВт, сеть 80 °C):

- дежурный режим при −25 °C держит обратку 45 °C;
- пуск с прогревом, приток 20 °C;
- сеть 50 °C: тепла не хватает, защита держит обратку и снижает вентилятор, аварии нет;
- отказ сети: авария «мороз», вентиляторы стоят, клапан открыт; после
  восстановления — самостоятельный перезапуск;
- компенсация уменьшает отклонение притока при падении температуры сети на треть;
- межсезонье: максимум клапана по наружной температуре, без подпора.
