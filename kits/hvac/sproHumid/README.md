# sproHumid

Влажный воздух и управление влажностью. Правила — `docs/pro-kits.md`.

| Компонент | Что делает |
|---|---|
| `Air` | функции для своих блоков: давление насыщения (Магнус, над водой и льдом), влагосодержание, относительная влажность, энтальпия, точка росы, температура мокрого термометра |
| `Psychro` | из температуры и относительной влажности: точка росы, влагосодержание (г/кг), энтальпия (кДж/кг), мокрый термометр; давление воздуха настраивается (высота над морем) |
| `RelHumidity` | относительная влажность того же воздуха при другой температуре: после нагревателя, на холодной поверхности (`condensing` — будет конденсат) |
| `Economizer` | наружный воздух выгоднее для охлаждения, чем вытяжной? Сравнение энтальпий с запасом; при отказе датчика влажности — по температурам |
| `Humidifier` | увлажнитель: ПИ по влажности помещения/вытяжки, ограничение влажности притока (второй регулятор, выбор меньшего), только при подтверждённом потоке воздуха с задержкой, гигростат-ограничитель, дискретная команда с гистерезисом |
| `Dehumidifier` | осушение охладителем: запрос охлаждения по превышению влажности и запрос догрева после охладителя (`reheat`) |

Точность: давление насыщения по Магнусу — в пределах 0,5 % от −40 до +60 °C;
тест сверяет значения с психрометрическими таблицами.

Лицензия: Apache 2.0.
