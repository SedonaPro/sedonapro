# sproHal

Ввод-вывод, не зависящий от платы. Компонент знает только имя канала (`DI1`,
`DO1`, `AI1`, `AO1`); пин, инверсию и масштаб задаёт файл платы `boards/<имя>.toml`.

| Компонент | Слоты | Что делает |
|---|---|---|
| `DigitalInput` | `channel`, `out`, `status` | читает дискретный вход |
| `DigitalOutput` | `channel`, `in`, `status` | пишет дискретный выход при изменении `in` |
| `AnalogInput` | `channel`, `out`, `status` | читает аналоговый вход в единицах платы |
| `AnalogOutput` | `channel`, `in`, `status` | ШИМ или ЦАП; `in` в единицах платы (по умолчанию 0–100 %) |
| `HalBoard` | `board`, `backend`, `channels`, `names` | показывает плату и список её каналов |

`status`: `ok`, `noChannel` (нет такого канала на плате), `wrongKind` (вход
вместо выхода и наоборот), `ioError` (пин не открылся или не читается).

Из кода Sedona доступен класс `Hal`: `find`, `kind`, `name`, `open`, `read`,
`write`, `count`, `board`, `backend`.

Устройство: `native/sproHal_Hal.c` (поиск канала, инверсия, масштаб) →
`backends/<hal>/` (сырой доступ к железу) → `spro_board.c` (таблица каналов,
генерирует `./spro` из файла платы). Номер нативного kit: 122.

`Assembly` — основа конфигураторов (`sproAhu::Ahu`, `sproPumpSt::PumpStation`):
блоки по опциям с сохранением настроек при пересборке, связи, свободные каналы
платы для новых точек и список входов-выходов.
