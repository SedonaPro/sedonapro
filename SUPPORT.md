# Support

Ask usage questions and discuss ideas in
[community Discussions](https://github.com/SedonaPro/.github/discussions).
Use an individual project's issues for reproducible defects.

Include the project/version, operating system, board (if any), SDK/toolchain,
expected result, actual result and the smallest reproduction you can share.
Attach logs and screenshots only after removing private data.

This is a volunteer community. Response times and hardware availability vary;
there is no promised support SLA.

For a suspected security issue, do not publish credentials or exploit details
in a public issue. Use the affected repository's private vulnerability reporting
when it is enabled. Otherwise ask a maintainer for a private reporting route
without disclosing the vulnerability publicly.
