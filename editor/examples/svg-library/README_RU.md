# Библиотека MCS и пример отдельных объектов

`mcs-base-library.json` — 7 ресурсов MCS с вариантами Off/On и пятью положениями заслонки/нагревателя. Импортируется через открытую «Библиотеку SVG» → «Импортировать библиотеку».

`mcs-scene.ui.json` — готовый UI-пакет с библиотекой и 9 отдельными объектами, 8 обычными виджетами. В «Обзор» выбрать app/sim/cascade, затем «Виды» → «Открыть пакет» → выбрать этот файл → «Открыть экран». Для живых значений предварительно подключиться к .184. На контроллер пример автоматически не записывался: «Сохранить на устройство» заменяет его mcs-ui.json, текущий пакет предварительно экспортировать.

`mcs-scene.sedona.json` — проект со снимком .184, который можно открыть офлайн через «Проект». Уставки в офлайн-режиме не записываются. Исходные размеры объектов сохраняются, отдельно масштабировать их не требуется.

Вентилятор в демонстрации связан с run/overloaded SimClock, а не с фактической ОС физического вентилятора. Заслонка использует valve.out/stuck как пример позиции и неисправности. Библиотечные объекты иллюстрируют модель: не выдавать эту мнемосхему за подтверждённую физическую установку.

После редактирования сохранить на ПК и при необходимости на устройство. Весь UI-пакет ограничен 512 KiB. SVG хранится один раз на ресурс; экземпляры ссылаются на assetId. Экран можно восстановить с контроллера без исходного JAR и библиотеки на ПК. `sources.json` фиксирует пути и хэши оригинальных ресурсов.
