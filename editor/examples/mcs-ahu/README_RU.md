# Пример MCS · каскад нагрева

Графика взята из установленного `kitPxMcs4svg-wb.jar` BCControl 4.12.2.16: заслонка, фильтр, нагреватель, вентилятор и штатные воздуховоды. Девять отдельных SVG включены в один векторный документ без растягивания отдельных библиотечных объектов. Исходные SVG лежат в `assets`; их размеры, SHA-256 и пути в модуле перечислены в `sources-and-bindings.json`. Файлы модуля не изменялись.

## Открыть с живыми значениями

1. Подключиться к `192.0.2.10:11876` в веб-редакторе.
2. В «Обзор» открыть `app → sim → cascade`.
3. Во вкладке «Виды» выбрать сохранённый пакет **«Пример MCS · каскад нагрева»** и нажать «Загрузить с ПК».
4. Нажать «Открыть экран».

Если пакет отсутствует в локальном списке, нажать «Открыть пакет» и выбрать `mcs-cascade.ui.json`. На контроллер пример автоматически не загружался. Кнопка «Сохранить на устройство» заменяет его общий `mcs-ui.json`, поэтому существующие виды следует предварительно экспортировать; пример и пользовательский пакет сейчас открываются отдельно, автоматического объединения нет.

## Открыть без подключения

В «Проект» открыть `mcs-cascade.sedona.json`: он содержит снимок структуры и значений устройства, SVG и виджеты. Затем выбрать `app/sim/cascade` и открыть экран через «Виды». Значения в этом варианте — сохранённый снимок, уставка недоступна для записи. `mcs-cascade.svg` можно использовать отдельно как фон.

## Привязки

| Виджет | Путь от app/sim/cascade | Слот |
|---|---|---|
| Положение клапана | valve | out |
| Воздух после нагрева | coil | airOut |
| Температура помещения | room | out |
| Расчёт модели | . | run |
| Температура воды | water | out |
| Задание на нагрев | master | out |
| Цель после шага | setpt | after |
| PID: признак good | master | good |

Клапан отображается долей 0–1: значение не умножалось на 100. Поле «Цель после шага» — параметр StepSignal.after, а не выход регулятора; его изменение требует отдельных «Подготовить» и «Подтвердить». Проверка примера выполнялась только чтением, без изменения уставок.

Символы заслонки, фильтра и вентилятора иллюстрируют тракт; отдельных состояний этих устройств в данной модели нет, поэтому они не анимируются. Bool-индикаторы относятся именно к расчёту модели и признаку good PID. Это пример визуализации симуляционной модели, не схема подтверждённой физической установки.
